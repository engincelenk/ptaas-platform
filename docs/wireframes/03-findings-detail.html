Critical Offen CVE-2024-1337

SQL Injection in /api/users

api.acme-corp.de · entdeckt vor 2h
KI-Erklärung für Entwickler

Deine App fügt User-Eingaben ungeprüft in SQL-Queries ein. Ein Angreifer kann dadurch eigene SQL-Befehle ausführen — im schlimmsten Fall alle Passwörter auslesen oder Daten löschen. Das ist vergleichbar damit, jemanden direkt mit dem Server reden zu lassen, statt über einen Türsteher.

Schritt-für-Schritt Fix
1
Prepared Statements verwenden
Trenne SQL-Logik von Daten. Niemals Strings konkatenieren.
// ❌ Unsicher db.query("SELECT * FROM users WHERE id = " + req.params.id) // ✅ Sicher db.query("SELECT * FROM users WHERE id = ?", [req.params.id])
2
Input validieren
Prüfe, dass IDs wirklich Zahlen sind, bevor sie in die DB gehen.
const id = parseInt(req.params.id, 10); if (isNaN(id)) return res.status(400).json({ error: 'Invalid ID' });
3
Deployment & Verification
Deploy die Änderung und markiere das Finding als „Behoben". Wir verifizieren automatisch innerhalb von 24h.
