Implementierungs-Hinweise

CSS Variables
Alle Wireframes nutzen --bg, --text, --accent etc. → 1:1 auf TailwindCSS-Custom-Properties übertragbar.
Skeleton-Shapes
Skeleton-Shapes spiegeln Content-Shapes exakt. Kein Layout-Shift beim Laden → bessere CLS-Score.
Breakpoints
Wireframes zeigen Desktop (1280px+). Mobile-Breakpoints: Sidebar → Bottom Nav, Grid → 1 Spalte.
Persona-Persistenz
Persona-Toggle-Wahl in localStorage speichern → bleibt über Page-Reloads. Default: Developer für neue User.
