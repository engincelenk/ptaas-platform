A11y Checklist — WCAG 2.1 AA
8 implementiert · 2 Dev-Notes
Fokus-Ring sichtbar (1.4.11)✓ Implementiert
outline: 3px solid #2563eb auf allen interaktiven Elementen. Kontrast 3:1 vs. Hintergrund.
Inline-Select Labels (1.3.1)✓ Implementiert
Jeder Status-Select hat <label class="vh"> mit Kontext: „Status für [Finding-Name]".
Persona Toggle (4.1.2)✓ Implementiert
role="group" + aria-pressed statt CSS-only Toggle. Screen Reader: „Developer Umschalter, gedrückt".
Notification Flyout (4.1.3, 2.1.1)✓ Implementiert
Disclosure Pattern: aria-haspopup="dialog", aria-expanded, ESC schließt + Fokus-Return.
Icon-Only Buttons (1.1.1)✓ Implementiert
Alle Icon-Buttons haben aria-label: „Einstellungen", „Benachrichtigungen (3 ungelesen)", „Abbrechen".
Live Regions (4.1.3)✓ Implementiert
Status-Änderungen, Scan-Fortschritt, Critical-Alerts als role="status" / aria-live.
Accordion (4.1.2)✓ Implementiert
aria-expanded="true/false" auf Accordion-Header. aria-controls zeigt auf Body-ID.
Farbkontrast (1.4.3)✓ Implementiert
Text auf Hintergrund ≥ 4.5:1. Badge-Text: Critical #991b1b auf #fef2f2 → 5.8:1. Accent #e86d30 auf #fff → 3.2:1 (Non-Text).
Scan-Progress (1.4.3)🔧 Dev-Note
Fortschrittsbalken braucht role="progressbar", aria-valuenow, aria-valuemin="0", aria-valuemax="100".
PDF-Ring-Progress (1.4.3)🔧 Dev-Note
SVG-Animation braucht prefers-reduced-motion: Animation pausieren wenn User-Präferenz gesetzt. @media (prefers-reduced-motion: reduce).
